# 🔎 Verificador de Idade

Projeto desenvolvido para calcular a idade de uma pessoa com base no seu ano de nascimento e apresentar uma imagem correspondente à sua faixa etária.

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento web, principalmente JavaScript e manipulação do DOM.

##  Demonstração

Acesse o projeto: [Verificador de Idade](https://jaobentivi07.github.io/Verificador_de_idade/)

## 🛠️ Tecnologias utilizadas

- **HTML5:** Estrutura da página.
- **CSS3:** Estilização e organização dos elementos.
- **JavaScript:** Lógica de cálculo da idade, validações e manipulação do DOM.

## ⚙️ Como funciona?

1. O usuário informa seu ano de nascimento.
2. Seleciona o sexo.
3. Clica no botão **Verificar**.
4. O JavaScript calcula a idade com base no ano atual.
5. O sistema identifica a faixa etária e apresenta uma imagem correspondente.

## 📂 Estrutura do projeto

- `index.html` – Estrutura principal da aplicação.
- `estilo.css` – Estilização da página.
- `script.js` – Lógica e funcionalidades do verificador.
- Arquivos `.png` – Imagens utilizadas para representar as faixas etárias.

## 🎯 Objetivo

Praticar conceitos de programação com JavaScript, incluindo funções, condicionais (`if/else`), variáveis, eventos e manipulação do DOM.
